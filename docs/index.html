What it checks

Manifest & permissions
Validate entrypoints and catch API calls that need network, filesystem, clipboard, or other permissions.
Compatibility
Check UXP and Photoshop API versions, unsupported CSS and HTML, deprecated APIs, and unavailable Node modules.
Host coverage
All five hosts get shared UXP checks, including manifest permissions and runtime compatibility. Photoshop additionally gets host API version and modal checks. Version 0.3.0 includes runtime mappings for Media Encoder and After Effects beta builds.
Photoshop modal execution
Find state changes outside executeAsModal, unawaited work inside modal callbacks, and unhandled rejections.

Start linting

Run once in a terminal

From your UXP project directory, run the CLI. It discovers UXP manifests and reports file and line numbers.

npm exec --package=eslint-plugin-uxp-lint -- uxp-lint .

Use Cursor or VS Code

Install ESLint (dbaeumer.vscode-eslint) in your editor. Install the package in your UXP project and generate a config. Open a source file to see findings in Problems.

npm install -D eslint eslint-plugin-uxp-lint
npx uxp-lint --init
npx eslint .

The CLI prints a snippet if you already have an ESLint config. Run npx uxp-lint --init-types for native UXP autocomplete in Cursor and VS Code. Autocomplete setup
